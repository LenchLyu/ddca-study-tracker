# 给数据库 Agent 的搭建提示词

请根据本仓库的 `data/tasks.json`、`schema.json` 和 `docs/notion-setup.md`，为我建立 DDCA 自学进度台。

使用两张关联表“学习任务”和“学习记录”，保留 72 项任务的官方编号、标题、年份、资料链接与验收标准。依据任务 `code` 重新建立 `prereq` 和 `related` 关系，不使用别人的 Notion 页面 ID。任务 JSON 中的 `content` 作为任务详情页内容。

建立文档所述的视图、时长汇总和仪表盘。理论课、Homework、Lab 分别统计完成率；辅助选学不计入分母。一次日志关联多个任务时均分用时，总学习时长只计算原始日志一次。

我有一定基础，以课件为主，录像按需补充。所有任务初始化为未开始、未评估；学习日期、复习日期保持空白，不添加假学习记录，不设置提醒。Lab 分开记录仿真通过和上板通过。

先检查是否已有同名进度表，避免重复创建。创建目标没有指定时，使用平台允许的私有位置。核对最终记录数、关系目标、视图筛选和公式输入；不支持的能力必须说明，不能仅按视图名称声称筛选已经生效。最后返回使用入口和简短更新方法。
